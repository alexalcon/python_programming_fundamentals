# CLAUDE.md

## Project
Learning project to learn Python programming fundamentals through hands-on coding exercises applied to algorithmic trading. No third party libraries are used, just the Python standard library.

## Dev environment tips
- Use the conda env `python_programming_fundamentals` for this project.
- Make sure to activate the environment before running any Python scripts:
  ```bash
  conda activate python_programming_fundamentals
  ```

## Coding Style Guidelines
- Always use the skill `python-pep8-comments` to code any Python script or module according to PEP 8 guidelines.
- Always use this structure in any Python single script or module, at the beginning of the file as a docstring header:
